# Renewal_sub — 서브 페이지 수정 초안

`original/`은 그대로 두고, 서브 페이지를 고친 사본을 이 폴더에 둡니다.
에셋(css/js/theme)과 다른 페이지 링크는 `../../original/`을 가리킵니다. 새로 만든 파일만 `assets/`에 있습니다.

## s1/s1_3.html — CCUS/블루수소

기존 섹션은 그대로 두고, 맨 아래에 `article.arti5` "수소 생산·연료전지 연계 탄소 포집 기술"을 추가했습니다.

- 스타일: `assets/css/s1_3-h2.css` (기존 `.s13 .arti2~4` 규칙과 같은 값)
- 이미지: `assets/images/s1_3/` (브로슈어 이미지에서 잘라 만듦)

### 오픈 전 확인할 것
- 실적 고객명은 브로슈어처럼 "OO"로 가렸습니다. 실명 공개 여부 확인.
- 현장 사진 2장(2024.12 촬영)이 어느 현장인지 확인. 수소 현장이 아니면 캡션은 그대로 두거나 수소 현장 사진으로 교체.
- 연료전지 시장 수치는 내부 발표자료 기준이라 외부 출처 확인 필요.
