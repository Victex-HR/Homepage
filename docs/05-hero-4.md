# 05. Renewal_4 — 히어로 4안

> Renewal_1(1-1안)과 같은 구성(좌측 타이틀 · 중앙 플랜트 사진 · 우측 CCUS/원전해체 패널 · 하단 지표)에,
> 1-1안 시안 이미지와 거의 같은 느낌이 나도록 배경·사진·패널 효과를 다시 만든 버전입니다.

## 1. 요청 사항과 적용

| 요청 | 적용 |
|---|---|
| 중앙(좌측) 사진은 첨부 1번 원본 | `hero-plant.jpg/.webp` — 1667×944 원본 해상도 그대로. 탱크 T-501A·B, 철골 포집 설비, VICTEX 탱크로리 |
| 우측 하단 사진은 첨부 2번 원본 | `hero-nuclear.jpg/.webp` — 436×604 원본 그대로. 패널 왼쪽 약 64% 폭에 확대 없이 표시 |
| 전체 효과는 첨부 3번(시안)과 거의 같게 | 밝은 화이트 블루 배경 + 가는 선이 꼬이며 흐르는 실크 물결, 거의 불투명한 흰 유리 패널과 사선 경계의 흰 선·옅은 그림자, 시안과 같은 글자색 |
| Renewal_1의 배경 효과·색감이 아쉬움 | 단색 그라데이션 + 굵은 곡선 대신, 시안처럼 수십 가닥의 가는 선으로 된 실크 물결(`hero-silk.svg`)과 흰 빛 번짐으로 교체 |
| Renewal_1 사진이 흐림 | PDF에서 뽑은 저해상도 사진(806px)을 키워 쓰던 것을 원본(1667px)으로 바꾸고, 사진 위 흰 막과 유리 흐림(blur)을 걷어냄 |
| 우측 상단 아이콘은 첨부 4번, 진하게 | CO₂ 구름 아이콘 — 원본은 불투명도 15%의 흰 선이라, 불투명도를 100%로 키우고 진한 남색(#163a6e)으로 칠함 (`icon-co2.png`) |

원전해체 패널의 원자 아이콘도 같은 남색으로 맞췄습니다.

## 2. 파일

| 파일 | 내용 |
|---|---|
| `Renewal_4/index.html` (`HERO : START ~ END`) | Renewal_1과 같은 마크업. 실크 물결 이미지, 원본 사진, CO₂ 아이콘으로 교체 |
| `Renewal_4/assets/css/hero.css` | Renewal_1 스타일 + 4안 배경·사진·패널·글자색 |
| `Renewal_4/assets/js/hero.js` | Renewal_1과 같음 (소개 영상 창) |
| `Renewal_4/assets/images/hero/hero-silk.svg`, `hero-silk-panel.svg` | 실크 물결 배경 — `python3 tools/silk_svg.py`로 다시 만들 수 있음 (선 굵기·진하기·모양 조정 가능) |

## 3. 확인

- 1920 / 1366 / 1024 / 390px 화면 확인
- 낮은 창(520~900px 높이) × 7가지 폭에서 잘림·겹침 없음
- 소개 영상 창: 가운데 표시, Space·Esc·Tab·더블클릭·바깥 클릭 정상
- 헤더와 히어로 외 6개 섹션은 원본과 픽셀 차이 0

## 4. 참고

- 첨부 1번 사진은 하늘·구름이 진해서, 시안처럼 위쪽을 흰색으로 날리고 탱크가 소개 문구 오른쪽에서 시작하도록 위치를 잡았습니다. 철골 오른쪽 끝은 CCUS 패널 뒤로 들어갑니다.
- 시안 이미지는 화면 비율이 가로로 더 길어서(약 2.4:1), 1920×1080처럼 세로가 긴 화면에서는 사진이 시안보다 크게 보입니다.

## 5. 검토 결과 (2026-10-05)

검토 에이전트 2개(시안 일치도, 반응형·접근성)가 찾은 문제 중 재현으로 확인된 10건을 고쳤습니다.

| 구분 | 수정 내용 |
|---|---|
| 사진 선명도 | 실크 물결의 흰 빛 번짐이 탱크·철골 아래쪽을 덮어 대비를 절반으로 떨어뜨리던 문제 수정 — 빛 번짐은 사진이 없는 왼쪽 아래에만 옅은 하늘색으로, 리본은 사진 앞에서 끝나도록 |
| 색감 | 배경·원전해체 패널을 시안처럼 하늘색 톤으로 (왼쪽 아래 하늘색 번짐 추가) |
| CCUS 패널 | 평소엔 깨끗한 흰 유리(사진 숨김), 마우스를 올리면 사진이 나타나되 글자 대비 4.5:1 이상 유지 |
| 글자 | 패널 제목·설명·"자세히 보기"를 시안 크기로, 링크 색을 시안의 청회색으로, 제목 강조색과 줄간격 조정 |
| 실크 물결 | 위 패널 물결이 설명 문구 끝에서 꼬이던 것을 오른쪽 아래 구석으로 이동 |
| 반응형 | 세로형 데스크톱(1024×1366)에서 탱크와 철골이 함께 보이도록, 낮은 창(540~620px)에서도 CO₂ 아이콘 유지, 모바일에서 Contact us 버튼과 카드 문구 겹침 방지 |

확인: 7가지 폭 × 8가지 높이에서 잘림·겹침 없음, 헤더와 히어로 외 6개 섹션은 원본과 픽셀 차이 0.
