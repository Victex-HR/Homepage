# 06. Renewal_3 (3-1안) · Renewal_5 (5안) — 3부문 사업모음

두 시안은 같은 구성(위: 회사 소개 + 사옥 사진 + 지표 4개, 아래: CCUS / 원전해체 / 드라이아이스 카드 3개)을 공유합니다.
스타일 파일도 같고(`assets/css/hero.css`), `article`의 변형 클래스(`hero--r3`, `hero--r5`)로만 모양을 나눴습니다.

## 1. 화면 구성 (공통)

- **위 왼쪽**: 빨간 선 + `INDUSTRIAL TECHNOLOGY SOLUTIONS`, 제목 "(주)빅텍스"(페이지 `h1`), 영문 상호 "VICTEX Co., Ltd.", "환경·에너지·산업의 미래를 여는 기술 전문기업", 버튼 COMPANY(회사 소개) · CONTACT US(문의)
- **위 오른쪽**: 빅텍스 사옥 사진(현행 사이트 COMPANY 섹션 사진), 아래에 지표 4개 — 2000년 설립연도 · 30+ 보유특허 · 500+ 납품실적 · 3대 핵심사업
- **배경**: 하늘색 그라데이션 + 소개 문구 아래에서 사옥 쪽으로 휘어 오르는 실크 물결(`hero-silk-top.svg`, `tools/silk_svg.py`)
- **아래 카드 3개**: 번호, 사진(위·아래가 하늘빛 안개로 녹아듦), 영문 라벨, 사업명 — 각 사업 페이지로 연결. 마우스를 올리면 사진이 조금 커지고 진해짐

## 2. 두 시안의 차이

| | Renewal_3 (3-1안 · PDF 시안) | Renewal_5 (5안 · 첨부 1번 구성) |
|---|---|---|
| 카드 모양 | 화면 끝까지 붙은 타일, 경계는 얇은 흰 선 | 간격을 둔 카드, 흰 테두리와 옅은 그림자 |
| 아이콘 | 없음 | 카드마다 원형 아이콘 — CCUS: CO₂ 구름, 원전해체: 원자, 드라이아이스: 눈꽃 |
| 화살표 | 없음 | 있음 (마우스를 올리면 오른쪽으로 이동) |
| CCUS 사진 | 제안서의 탱크로리·액화탄산 탱크 사진 | 첨부 2번 (같은 현장, 다른 컷) |
| 원전해체 사진 | 제안서의 원전해체 마스트·철골 사진 | 첨부 3번 (원격 로봇) |
| 드라이아이스 사진 | 현행 사이트 드라이아이스 페이지의 펠릿 사진 | 첨부 4번 (블록 생산 라인) |

## 3. 확인

- 1920 / 1366 / 390px 화면 확인, 6가지 폭 × 7가지 높이에서 글자 잘림·겹침·가로 스크롤 없음
- 섹션 내비 점이 지표·카드 글자와 겹치지 않음 (1024~1440px)
- 헤더와 히어로 외 6개 섹션은 원본과 픽셀 차이 0

## 4. 오픈 전 확인이 필요한 항목

1. **지표 수치**: 설립연도는 2000년으로 확정했습니다(시안의 2007에서 수정, 현행 사이트·Renewal_1·4와 같음). 30+ 보유특허, 500+ 납품실적은 확인이 필요합니다.
2. **사옥 사진**: 현행 사이트 사진이 810×480이라 큰 화면에서는 약 1.3배 확대됩니다. 고해상도 원본이 있으면 교체를 권장합니다.
3. **드라이아이스 카드 링크**: 지금은 "드라이아이스너겟제조기"(`s1_1_1`)로 연결합니다. "드라이아이스"(`s1_6`) 페이지가 맞으면 바꾸겠습니다.
