## 2. 화면 구성

```
┌ header (현행 메뉴 유지) ───────────────────────────────────────────────┐
│                                         ╱ CCUS 탄소중립 통합 솔루션      │
│ 탄소중립과 원자력산업의    [CCU 플랜트  ╱  탄소 포집부터 활용·저장까지…   │
│ 지속가능한 미래             사진, 가장자리  자세히 보기 →               │
│ 빅텍스는 CCUS를 통한 …      페이드]      ╱────────────────────────────── │
│                                        ╱ [로봇 사진] ⚛ 원전해체 /        │
│ ▶ 빅텍스 소개 영상 재생하기            ╱              원자력산업 솔루션   │
├────────────────────────────────────────────────────────────────────────┤
│ 2000년 설립연도 │ 120+ 전문 인력 │ 265억 2025년 매출 │ 독자 기술 │ 글로벌 파트너십 │
└────────────────────────────────────────────────────────────────────────┘
```

- **1024px 이상**: fullPage 1번 섹션 안에 한 화면으로 들어갑니다. 1600px 이하에서는 패널 아이콘이 제목 위로 올라갑니다.
- **1024px 미만**: fullPage가 일반 스크롤 모드로 바뀌므로 타이틀 → 사진 → 사업 카드 2개 → 지표 순서로 쌓입니다.
- 첫 화면에서는 "맨 위로" 버튼을 숨기고, "Contact us" 버튼은 작게 줄여 지표 바 오른쪽 끝에 둡니다(사업 패널 문구와 겹치지 않도록).

## 4. 오픈 전 확인이 필요한 항목

1. **고해상도 원본 사진**: 지금 사진은 PDF에 들어 있던 축소본입니다(중앙 806×593, 원전해체 314×556). 원본 파일을 주시면 같은 파일명으로 교체만 하면 됩니다. 중앙 사진은 가로 2000px 이상을 권장합니다.
2. **지표 수치**: 2000년 설립, 120+ 전문 인력, 265억(2025년 매출)은 시안 그대로입니다. 3안 시안에는 설립연도가 2007로 적혀 있어, 정확한 값을 확인해 주세요.
3. **소개 영상**: 현재는 메인에 있던 너겟제조기 영상(YouTube `ZYizun2skEA`)을 연결했습니다. 회사 소개 영상이 따로 있으면 버튼의 `data-hero-video` 값만 바꾸면 됩니다.
4. **상단 메뉴(GNB)**: 시안의 메뉴(회사소개, 사업분야, 기술력, 지속가능경영, 투자정보, 홍보센터, 인재채용, 고객지원)는 아직 페이지가 없어 현행 메뉴를 유지했습니다. 메뉴 개편은 별도 단계로 진행합니다.
5. **"자세히 보기" 연결 페이지**: CCUS → 빅텍스 CCU Solution(`s1_3`), 원전해체 → 원전 해체 및 원격로봇 시스템(`s2_4`).
