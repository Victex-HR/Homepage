- **1024px 이상**: fullPage 1번 섹션 안에 한 화면으로 들어갑니다. 1600px 이하에서는 패널 아이콘이 제목 위로 올라갑니다.

- 첫 화면에서는 "맨 위로" 버튼을 숨기고, "Contact us" 버튼은 작게 줄여 지표 바 오른쪽 끝에 둡니다(사업 패널 문구와 겹치지 않도록).

## 4. 오픈 전 확인이 필요한 항목

1. **고해상도 원본 사진**: 지금 사진은 PDF에 들어 있던 축소본입니다(중앙 806×593, 원전해체 314×556). 원본 파일을 주시면 같은 파일명으로 교체만 하면 됩니다. 중앙 사진은 가로 2000px 이상을 권장합니다.
2. **지표 수치**: 2000년 설립, 120+ 전문 인력, 265억(2025년 매출)은 시안 그대로입니다. 3안 시안에는 설립연도가 2007로 적혀 있어, 정확한 값을 확인해 주세요.
3. **소개 영상**: 현재는 메인에 있던 너겟제조기 영상(YouTube `ZYizun2skEA`)을 연결했습니다. 회사 소개 영상이 따로 있으면 버튼의 `data-hero-video` 값만 바꾸면 됩니다.
4. **상단 메뉴(GNB)**: 시안의 메뉴(회사소개, 사업분야, 기술력, 지속가능경영, 투자정보, 홍보센터, 인재채용, 고객지원)는 아직 페이지가 없어 현행 메뉴를 유지했습니다. 메뉴 개편은 별도 단계로 진행합니다.
5. **"자세히 보기" 연결 페이지**: CCUS → 빅텍스 CCU Solution(`s1_3`), 원전해체 → 원전 해체 및 원격로봇 시스템(`s2_4`).

## 5. 검토 결과 (2026-10-04)

검토 에이전트 4개(시안 일치도, 반응형, 접근성, 기능·회귀)가 찾은 문제 중, 별도 에이전트가 직접 재현해 확인한 것만 고쳤습니다.

| 구분 | 수정 내용 |
|---|---|
| 소개 영상 창 | 화면 왼쪽 위에 붙어 닫기 버튼이 화면 밖으로 나가던 문제 수정(가운데 정렬, 화면 높이에 맞춘 크기). Space 키로 열 때 섹션이 넘어가던 문제, 창 안에서 Tab이 막히던 문제, 더블클릭하면 바로 닫히던 문제 수정 |
| 시안 일치 | 소개 문구·재생 버튼을 시안 비율로 키움, 하단 지표를 구분선 사이 가운데 정렬, 원전해체 사진 오른쪽 경계를 부드럽게, CCUS 설명 줄바꿈 유지 |
| 반응형 | 높이가 낮은 창(520~760px)에서 패널 내용·재생 버튼이 잘리거나 겹치지 않도록 글자와 아이콘 크기를 화면 높이에 맞춤, 세로형 데스크톱(1024×1366)에서 사진 위치 조정, 모바일에서 Contact us 버튼을 작게 모서리로 |
| 접근성 | 사업 카드 키보드 초점 테두리를 잘 보이게, 섹션 내비 점 대비 3:1 이상 |
| 기타 | 페이지를 처음 열 때 Contact us·맨 위로 버튼이 잠깐 원래 자리에 보였다 옮겨 가던 깜빡임 제거 |

확인: 7가지 폭(1024~1920) × 8가지 높이(520~900) 조합에서 잘림·겹침 없음. 헤더와 히어로 외 6개 섹션은 원본과 픽셀 차이 0.

참고: YouTube 영상 안을 클릭한 뒤에는 Esc 키가 영상 쪽으로 들어가서 창이 닫히지 않습니다(외부 영상 프레임의 일반적인 동작). 이때는 닫기 버튼이나 바깥 영역을 누르면 닫힙니다.
