## 1. 작업 환경 — 수정할 파일만 따로 떼어 둠

`renewal/`은 `original/`을 복사해서 만들었고, 히어로 관련 코드만 별도 파일로 분리했습니다.
현재 상태는 원본과 **픽셀 단위로 동일**합니다(1920 / 1366 / 800 / 390px 비교, 차이 0px).

| 파일 | 내용 |
|---|---|
| `renewal/index.html` — `HERO : START ~ END` 주석 블록 | 히어로 마크업 |
| `renewal/assets/css/hero.css` | 히어로 스타일 전체 (legacy `main.css`와 `media.css`에서 옮겨 옴) |
| `renewal/assets/js/hero.js` | 슬라이더, 재생/정지, SCROLL 동작 (인라인 스크립트에서 옮겨 옴) |
| `renewal/assets/images/hero/` | 히어로 이미지 3장 + 컨트롤 아이콘 |
| `renewal/assets/css/tokens.css` | 현행 디자인 값을 CSS 변수로 정리 (색상, 폰트, 헤더 높이, 컨테이너) |

- 위 파일 외의 legacy 코드(`renewal/theme/...`)에는 히어로 관련 규칙이 남아 있지 않습니다. 그래서 히어로를 고쳐도 다른 섹션에는 영향이 없습니다.
- 서브 페이지 링크는 `../original/...`로 연결되어 있어, 리뉴얼 중에도 사이트 전체를 둘러볼 수 있습니다.
- 다른 섹션이 바뀌지 않았는지 확인하려면 `npm run shots`를 실행합니다(§6).

## 2. 현행 히어로 사양

### 2.1 구조
```html
<div class="section section1" data-anchor="MAIN">        ← fullPage 1번 섹션
  <article class="mv_sec">
    <div class="owl-carousel mv_owl">
      <div class="item mv01">                              ← 슬라이드 ×3
        <div class="mv_img"></div>                        ← 배경 이미지 (CSS background)
        <text_wrap class="ct2"><text_box>                 ← 비표준 태그
          <h3 class="fz60">제목</h3>
          <p class="fz20">설명</p>
        </text_box></text_wrap>
      </div> …
    </div>
    <div class="owl_b"> .mv_play.on / .mv_stop </div>     ← 재생/정지 토글
    <div class="mv_scroll"><a href="#n"><img scroll_mv.png></a></div>
  </article>
</div>
```

### 2.2 슬라이드 콘텐츠
| # | 제목(h3) | 설명(p) | 이미지 |
|---|---|---|---|
| 1 | (주)빅텍스 / 드라이아이스 너겟 제조기 | C사, K사, E사 등 국내 3대 온라인 식품 배송업체 모두 우수한 품질이 입증된 (주)빅텍스의 드라이아이스 너겟제조기를 도입하여 사용하고 있습니다. | `hero-01.jpg` (원본 `mv00.jpg`) — 너겟 제조 라인 공장 전경 |
| 2 | (주)빅텍스 / CO₂ Revert Recovery System | 드라이아이스 제조공정에서 버려지는 CO₂를 포집하여 원료로 재사용함으로써 드라이아이스 생산성을 극대화할 수 있습니다. | `hero-02.jpg` (원본 `mv02.jpg`) |
| 3 | (주)빅텍스 CCU 솔루션 / Carbon Capture and Utilization | (주)빅텍스는 이산화탄소(CO₂)를 배출단계에서 포집, 액화하여 재사용하는 CCU 플랜트에 대한 토털 엔지니어링 솔루션을 제공합니다. | `hero-03.jpg` (원본 `mv03.jpg`) |

이미지는 모두 **1920×870 JPG**(380~480KB)입니다. 화면 높이 `100vh - 100px` 영역을 `background-size: cover`로 채우기 때문에 세로로 긴 화면에서는 좌우가 많이 잘립니다.

### 2.3 동작
| 항목 | 현행 |
|---|---|
| 슬라이더 | Owl Carousel 2, `animateIn/Out: fadeIn/fadeOut`, `loop`, `items: 1` |
| 자동재생 | **꺼져 있음** (`autoplay:false`). 재생 버튼을 누르면 8초 간격으로 넘어감 |
| 진입 효과 | 배경: `scale(1.2)` → `scale(1)`, 6초(Ken Burns) / 제목: 0.3초 지연 후 아래에서 위로 페이드 / 설명: 0.6초 지연 |
| 내비게이션 | 이전/다음 화살표(10×17 PNG), 점 내비(활성 상태는 35×10 파란 pill), 재생/정지(7×10 PNG) |
| SCROLL | 아이콘이 위아래로 움직이는 애니메이션(3초). 클릭하면 fullPage `moveTo(2)` |
| 높이 | PC: `calc(100vh - 100px)` / ≤1024: `80vw` / ≤480: 헤더가 80px이 되면서 위 여백도 80px로 바뀜 |
| 텍스트 위치 | 위에서 `216px` 고정(≤1024: `15vw`). 1500px 컨테이너 기준이고, ≤1600px에서는 왼쪽 여백 20px |
| 컨트롤 위치 | `bottom: 341/355/335px`, `margin-left: -750px` 등 **고정 수치** 사용 |
| 제목 크기 | 60px → 45px(≤1024) → 35px(≤640) → 5vw(≤480) |

### 2.4 현행 문제점 (리뉴얼할 때 함께 해결할 것)
1. **재생 상태 표시 오류**: 자동재생이 꺼져 있는데 일시정지(II) 아이콘이 보입니다.
2. **고정 수치 배치**: 컨트롤을 `bottom: 341px` 기준으로 배치해서, 화면 높이가 다르면 텍스트와 컨트롤 사이 간격이 달라집니다. 짧은 노트북 화면에서는 겹칠 수 있습니다.
3. **시맨틱·접근성**: 비표준 태그를 쓰고, 제목이 `h3`이며, 슬라이드 영역 정보(aria)와 키보드 조작이 없습니다. 움직임 줄이기 설정도 지원하지 않습니다.
4. **성능**: LCP 이미지가 CSS 배경이라 preload, 반응형 이미지, WebP를 쓸 수 없습니다.
5. **메시지**: 첫 슬라이드는 드라이아이스 장비인데 GNB 1순위와 meta description은 CCUS입니다. 회사 포지셔닝을 하나로 정해야 합니다.
6. SCROLL 링크가 `href="#n"`이라 클릭하면 주소창 해시가 `#n`으로 바뀝니다.

## 4. 권장 기술 방향 (제안)

- **마크업**: `<section class="hero" aria-roledescription="carousel">` 구조로 만들고, 메인 메시지는 `h1`에 넣습니다. 비표준 태그는 쓰지 않습니다.
- **이미지**: `<picture>`와 `srcset`으로 WebP·JPG를 함께 제공하고, 첫 슬라이드는 `fetchpriority="high"`로 preload합니다. 동영상을 쓴다면 `poster`, 음소거, `playsinline`을 넣고 모바일에서는 이미지로 대체합니다.
- **슬라이더**: 지금처럼 Owl Carousel을 써도 되지만, 이미 로드 중인 **Swiper**를 쓰면 접근성 모듈(a11y)과 터치 조작을 기본으로 지원합니다. 슬라이드가 1장이면 라이브러리가 필요 없습니다.
- **레이아웃**: 고정 수치 대신 flex/grid로 텍스트와 컨트롤을 한 컨테이너 안에 배치하고, 높이는 `min(100svh - header, 900px)`처럼 위아래 한계를 둡니다.
- **모션**: `prefers-reduced-motion`이 켜져 있으면 Ken Burns 효과와 자동재생을 끕니다. 재생/정지 버튼은 실제 상태와 맞게 표시하고 `aria-pressed`를 붙입니다.
- **스타일 값**: `tokens.css` 변수를 사용해서, 이후 다른 섹션을 리뉴얼할 때도 같은 값을 쓸 수 있게 합니다.
